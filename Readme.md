### 📚 Resource for the week

I recommend using the official PostgreSQL tutorial as your primary reference because it introduces the topics in a practical order—from installation and creating databases to SQL, joins, transactions, and advanced features. ([PostgreSQL][1])

For video learning, the freeCodeCamp PostgreSQL course is one of the most complete beginner resources and closely follows the concepts you'll need. ([YouTube][2])

Now that your repository structure is ready, the next step is simply to start with **01-Introduction**. Once you're done with that, move to **02-SQL-Basics** without worrying about the later folders yet.
